# Personal Portfolio Website

A simple, responsive personal portfolio webpage built using only **HTML** and **CSS**.
Created by **Mohith Kumar**, B.Tech 1st year student, as part of a Creative HTML & CSS Webpage Project.

## Features

- Navigation bar linking to every section
- Hero section with profile introduction
- Skills section with progress bars
- Projects and achievements shown as cards
- Contact form
- Responsive design (works on desktop and mobile screens)

## Technologies Used

- HTML5
- CSS3 (Flexbox, media queries)

No JavaScript or frameworks are used. All CSS is inside the `<style>` tag of `index.html`.

## Project Structure

```
portfolio-repo/
├── index.html   # HTML + CSS combined
└── README.md    # Project description
```

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
